Customer Churn Analysis using SQL & Power BI

Project Overview

This project analyzes telecom customer churn behavior using SQL and Power BI. The dashboard identifies key churn patterns based on contract type, internet service, payment methods, and technical support.

Tools Used

- SQL
- Power BI
- Data Visualization
- KPI Analysis

Key Insights

- Month-to-month customers showed the highest churn rate
- Fiber optic users were more likely to leave the service
- Customers without tech support had higher churn
- Electronic check users contributed the highest churn

Dashboard Features

- KPI Cards
- Funnel Chart
- Interactive Slicer
- Customer Churn Visualizations
- Business Insights Section
