# Customer Churn Analysis using SQL & Power BI

## Project Overview
This project analyzes telecom customer churn patterns using SQL and Power BI.

## Tools Used
- SQL
- Power BI
- Data Visualization

## Key Insights
- Month-to-month customers showed highest churn
- Fiber optic users had higher churn
- Customers without tech support churned more

## Dashboard Features
- KPI Cards
- Funnel Chart
- Interactive Slicer
- Business Insights
